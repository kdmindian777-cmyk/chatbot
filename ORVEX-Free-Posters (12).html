1. What O.R.V.E.X is

O.R.V.E.X is a chat assistant that lives in one HTML file. You open it by double-clicking the file, and it runs in Chrome or Edge. It answers in English or Hindi, can speak and listen, shows photos, tells the weather, translates words, reads screenshots of questions, and keeps its API keys behind a password.

The file contains the page layout (HTML), the look (CSS) and all the logic (JavaScript). There is no server. Settings are saved inside the browser you use.

The AI part uses Google's Gemini through a free API key. Without a key, or without internet, O.R.V.E.X uses its smaller built-in replies.

The name. O.R.V.E.X stands for Online Research, Voice and Event eXpert. Wherever the app writes its name it is written with dots, O.R.V.E.X, so everyone can see that the name has a full form (section 17).

3. How O.R.V.E.X handles each message

When you press send, O.R.V.E.X checks the message in this fixed order and stops at the first match:

  1. A picture is attached: if you ask to change it (for example "remove the background" or "make it a cartoon") the AI edits it. Otherwise it is read like a screenshot of a question (needs a key).
  2. Weather question: words such as weather, temperature, forecast or climate (Hindi: मौसम, तापमान). It works for any place in the world.
  3. Request for O.R.V.E.X's hidden instructions: refused politely.
  4. Request for O.R.V.E.X's own code: answered with a different example chatbot.
  5. Full form question: "full form of O.R.V.E.X", "what does O.R.V.E.X stand for" and similar are answered at once.
  6. Platform question: "which platform or AI do you use?" is answered at once.
  7. Dictionary question: meaning or translation of a word the built-in dictionary knows.
  8. "Who developed you?" question: answered with the developer's name.
  9. Image request: "show me a picture of…", "draw…", "create a poster for…" and similar.
  10. Everything else: Gemini answers if a key is saved. If there is no key, or Gemini fails, the built-in replies answer instead.

Typed messages and spoken messages follow the same path. Spoken ones are first checked against the voice commands (section 8).

4. AI answers with Gemini

Choosing a model. O.R.V.E.X asks Google which Gemini models your key can use, ranks them (newer is better, Flash is preferred, "lite" and "preview" versions rank lower) and saves that list in the browser. It tries up to four models in order. If a model is busy (errors 429, 500 or 503) it waits and retries once, then moves on. If the saved list is out of date (error 404) it refreshes the list once. For other errors, such as 400 or 403, it stops and shows the error with a hint on what to do (section 12).

If the AI fails. O.R.V.E.X shows "Couldn't reach the AI model just now" with the error text, a built-in reply, and a plain-language hint when the problem is the API key, the free limit or the connection.

Memory. The last 30 turns of the conversation (15 questions and answers) are sent along with each question, so short follow-ups like "why?" or "go on" make sense. Clearing the chat also clears this memory. The chat itself is not saved when you close or refresh the page.

Live web information and Web Search Grounding. O.R.V.E.X uses Google Search Grounding through your existing Gemini API key when you ask it to search the web, look up information, find sources, verify facts, or answer time-sensitive questions such as current news, weather, prices, scores and recent updates. It tries supported Gemini models and adds source links when Google returns grounding citations. If a Tavily key is saved (⚙ → 🔑 API Keys → Web search), O.R.V.E.X uses it first: it finds the web pages itself and Gemini writes the answer from them with numbered sources. A Google Custom Search key and Search Engine ID work as a second choice. Without any of these, it uses Gemini's own Google Search tool, which has its own quota. The 🌐 Web Search button in the top bar has three settings: Auto (searches only when the question needs live information), ON (searches the web for every question) and OFF (never searches). If source links cannot be shown, check that your Gemini API key is valid, the selected model supports Google Search Grounding, and your API quota is available.

Fast answers (⚡). Fast mode puts the quick Lite and Flash models first, tells the AI to answer right away in a warm, natural tone with only a few sentences, removes the artificial "thinking" pauses in built-in replies, and shortens the wait before a retry from 1.5 seconds to 0.4 seconds. It does not change how fast the voice speaks. The choice is remembered. A spoken Hindi reply also uses the fast model first, even when fast mode is off. Fast mode is for ordinary chat: for code, long writing and creative requests O.R.V.E.X automatically uses its best model and gives a full-length answer, even when ⚡ is on.

Screenshots. Paste an image with Ctrl+V or click 📎. A preview appears above the text box and you can add a note. O.R.V.E.X sends it to Gemini, which gives the final answer first and then a short step-by-step explanation. Very large screenshots (over 3 MB) are shrunk to at most 2,000 pixels on the long side, and unusual image formats are converted. A key is required.

How replies are displayed. Code appears in a dark block with the language label and colouring for comments, strings, numbers and HTML tags. Simple maths is shown with fractions, square roots, powers and subscripts. Web addresses become clickable links that open in a new tab.

5. Built-in mode (no key, or when the AI fails)

These are small, ready-made replies. They work without any key:

  • Rules: greetings, "who are you", the time, the date, jokes, colour themes, thank-you, goodbye and "what can you do". Each has an English and a Hindi version. Anything else gets one of four general replies, some of which suggest adding a Gemini key.
  • Dictionary: 395 words, English to Hindi and Hindi to English, each with the part of speech and an example sentence. It also works offline. Try "meaning of happy", "what does brave mean", "translate water", "book in hindi", "book ka matlab" or "खुशी का मतलब". If a word is not in the list, the question goes to the AI.
  • Facts: 40 built-in facts, shown when you are offline or the fact service does not answer in time.
6. Weather

Weather API key (optional). In ⚙ → 🔑 API Keys there is a box for an OpenWeather key. If one is saved, weather comes from OpenWeather and the card shows "OpenWeather". If the key is missing or not accepted (a new key can take up to a couple of hours to start working), O.R.V.E.X uses the free Open-Meteo service and the card says so.

Ask "weather in Delhi", "Mumbai weather" or "दिल्ली का मौसम". O.R.V.E.X shows a weather card with the temperature, conditions, humidity, wind and a 4-day forecast. This uses the free Open-Meteo service and needs no key, and it works for places all over the world.

Many places share a name (for example there is a Sakti in India and another in Indonesia). Write the place as City, State, Country, for example "weather in Sakti, Chhattisgarh, India". O.R.V.E.X then picks exactly that place. If you write only the city, O.R.V.E.X shows the best match, prefers India when it is used from India or in Hindi mode, and lists the other places with the same name so you can write the one you want.

If the place cannot be found and a Gemini key is saved, O.R.V.E.X searches the web for the weather instead. If you ask without a place, it asks which place you mean.

7. Pictures

What counts as an image request. A verb such as give, show, send, generate, create, draw, make, get, find, display, paint or design followed within a few words by image, picture, photo, pic, drawing, illustration, wallpaper or painting. Also messages that start with "draw", and phrases like "pictures of…".

Where pictures come from, in this order:

  1. Google Image Search, if both the Google key and the Search Engine ID are saved. Google has stopped letting new projects use this service, so it may fail. A failure is silent and O.R.V.E.X simply moves on.
  2. Wikimedia Commons, free and without a key. Good for charts, diagrams, maps, historical pictures and known people. Searches that contain explicit words skip this step.
  3. Pexels stock photos, if a Pexels key is saved. Good for general photos, not for specific diagrams.
  4. AI-generated picture from Gemini, if a key is saved. It tries up to three image models.
  5. Pollinations, a free picture generator that needs no key, as the last choice.

Posters, cards and banners. Requests such as "create a Hindi poster for Maa Bhawani Jagran with a red-and-gold theme" skip the photo search and go straight to the AI picture model, so the design is created for you. This works for posters, invitations, birthday and greeting cards, banners, flyers, logos, infographics, certificates and artwork. A Gemini key is needed for accurate text in the design.

Editing your own picture. Attach a picture with 📎 and say what to change, such as "remove the background", "make it a cartoon" or "add a blue sky". The AI returns an edited version.

Photo results appear as a grid of up to six pictures, each with the artist's name or "Wikimedia Commons". Clicking a picture opens it larger. The caption says "Real photo results for: …".

8. Voice

Speaking. O.R.V.E.X uses voices installed on the device.

  • English: a female voice in the style of Friday. It prefers an Irish-accent voice such as Niamh, then British female voices such as Sonia, Libby or Hazel, then any other English female voice.
  • Hindi: a female Hindi voice. Voices that run on the computer, such as Kalpana or Swara, come first because they start sooner. The online Google हिन्दी voice is used after them. A male voice is used only if nothing else exists, and then the pitch is raised slightly.
  • Speed and pitch: speed is always 0.95 (slightly slower than normal) and pitch is 1.2. The first sentence is spoken alone so speech starts quickly, and the rest is joined into longer pieces.
  • The speech engine is woken on the first click or key press, so the first spoken reply is not delayed.
  • When it speaks: always when you asked by voice, and for every reply when 🔊 is on or when you say "read replies aloud".

Listening. Press 🎤 and speak. The words appear in the text box as you talk. English mode uses the browser's language, and Hindi mode listens in Hindi (hi-IN). It works in Chrome or Edge and needs internet and microphone permission. Pressing 🎤 again stops it.

9. Hindi mode and Sanskrit mode

Sanskrit mode. Click the language button again to go EN → हिं → सं (Sanskrit). O.R.V.E.X then answers in Sanskrit written in Devanagari, and the greeting, hints and some messages are in Sanskrit or Hindi. Event Kit can also write in Sanskrit. Reading aloud and listening use the Hindi voice, because browsers have no Sanskrit voice or Sanskrit listening, so the Sanskrit sounds approximate. Built-in answers (without the AI) stay in Hindi. Sanskrit from the AI can contain mistakes, so check important text.

The EN / हि button switches everything at once: the opening line, the text-box hint, the bottom line, the built-in replies, the dictionary answers, the voice commands, the speaking voice, the listening language, the clock and the instruction given to the AI ("reply only in Hindi, in Devanagari script"). The chosen language is remembered.

The developer's name in Hindi. When someone asks who developed O.R.V.E.X, the Hindi answer is: मुझे राज्ञांश महंत ने विकसित किया है। In English the answer is "I was developed by Ragyansh Mahant."

10. API Keys and the password lock

Open ⚙, then tap 🔑 API Keys. A small box asks for the password (what you type shows as dots). After that, paste your Gemini key (free at ai.google.dev) and click Save. The other boxes (pictures, web search, weather) are optional. Changing or removing a saved key asks for the password again.

Your keys stay in your own browser. They are saved only on this device and are not visible to other people who open this page. Never share your keys with anybody, and do not use a key you are not willing to lose.

Portable copy. The download button makes a file that contains your keys in plain text. Keep that file private.

11. Privacy and protection
  • Your Gemini key is sent only to Google's Gemini service. The Pexels key goes only to Pexels, and the Google search key only to Google.
  • If someone asks for O.R.V.E.X's code, O.R.V.E.X gives a short, different example chatbot with no developer name and no key. If someone asks it to show its hidden instructions, it refuses. The AI is given the same rules.
  • These protections work inside the page. Anyone who opens the HTML file in a text editor, or uses the browser's developer tools, can still read what is stored in it. Real secrecy needs a server.
12. API keys: expiry, limits and what to do

Does a Gemini key expire? Free AI Studio keys do not show a fixed expiry date, and a key normally keeps working until it is deleted or blocked. But a key can stop working, and Google's message may say "API key expired" or "API key not valid". O.R.V.E.X treats these as the same problem.

Why a key can stop working:

  • it was deleted, or replaced by a new one
  • Google blocked it because it was found in a public place
  • the free limit (requests per minute or per day) was used up
  • billing or project settings changed
  • Google retired an AI model (O.R.V.E.X picks from the models your key can use, so it usually recovers by itself)

What O.R.V.E.X does when it happens. The chat shows the error, a built-in reply, and a plain hint: for an invalid or expired key it tells you to open API Keys and paste a new one, for a blocked key it tells you to create a new key, for the free limit it tells you to wait a minute, and for no connection it tells you to check the internet.

How to fix it (about two minutes):

  1. Go to ai.google.dev and choose Get API key, then Create API key.
  2. Copy the new key.
  3. In O.R.V.E.X open ⚙, then 🔑 API Keys, paste the key in the Gemini box and click Save.
  4. Send a message to test it.

Before you publish O.R.V.E.X online:

  • Do not put your own key inside a file that is public. Anyone can read the code of a web page and copy a key, and Google blocks keys it finds in public.
  • The simplest safe way is to publish a copy with no keys inside, so each visitor adds their own free key under 🔑 API Keys. It stays in their own browser.
  • A stronger way for many visitors is a small server in the middle that holds the key, so it never reaches a visitor's browser.
  • Use a separate key for the published copy, so you can switch it off without affecting anything else.
  • Watch your usage in Google AI Studio and create a fresh key from time to time.

15. Things to know
  • Online and offline. The AI, weather, pictures, fresh facts and voice listening all need internet. The bottom line says "Works only when you are ONLINE", but the built-in replies and the 395-word dictionary still work offline.
  • Saved in the browser: the keys, the scrambled password, the language, fast answers on or off, read-aloud on or off, and the lists of AI models. Browsers keep this separately for each profile and each way of opening the file, which is why a new computer or profile starts empty and the portable copy exists.
  • Google Image Search may not work. Google closed that service to new customers and plans to end it on January 1, 2027.
  • Fast answers start switched off the first time the file is opened. The last choice is remembered after that.
  • Voices depend on the device. If no female Hindi or English voice is installed, O.R.V.E.X uses the best one it finds. On Windows you can add Hindi under Settings, Time and language, Speech.
  • Code blocks have a Copy button, and HTML code also has a ▶ Run button that shows the page in a safe preview window.
  • Chat is not saved after a refresh. Use ⬇ to keep a copy.
  • Voice input needs Chrome or Edge, internet and microphone permission.

O.R.V.E.X is built to help like a top AI assistant. With a Gemini key it can do the things below. For code, long writing and creative requests it automatically uses its best model and gives a full-length answer. For quick chat it stays fast.

Presentations and professional designs. Presentations, educational slides, agriculture training material, farmer awareness material, certificates and invitations, reports, brochures, infographics and diagrams. Coding and digital projects. Websites, Python programs, simple games, interactive applications, chatbots and AI project ideas, with step-by-step guidance even for a complete beginner.

Teaching mode. When you ask for help to build or learn something, for example "help my younger sister make a simple AI chatbot", O.R.V.E.X acts like a patient teacher. It first says in one line what you will build, then gives numbered steps (Step 1, Step 2 and so on). Each step has a simple explanation, only the small piece of code for that step, and how to check that it works. The complete final code and the exact way to run it come at the end. It does not start by dumping a big block of code.

Fully working code. All code must be complete: every import and file included, no placeholders, no unfinished parts, checked before it is sent, and with the exact way to run it. Code appears in a dark block with a Copy button, and HTML code also has a ▶ Run button that shows the page in a safe preview window.

What it still cannot do. Create finished videos, create .pptx or Word files, or work without internet. The quality of every answer depends on the Gemini model connected to the key.

19. Which platform O.R.V.E.X uses

It also uses free services for weather (Open-Meteo), pictures (Wikimedia Commons, Pexels and Pollinations) and facts, and the browser's built-in tools for speaking and listening. If someone asks which platform it uses, O.R.V.E.X answers this directly.

20. Event Kit: everything for an event in one tap

Tap 🎉 in the top bar. Fill in the event name (the only required box), the date and time, the place, the theme and colours, the language (Hindi, English or both) and any extra details such as guests or a special programme. Then tap Create Event Kit.

O.R.V.E.X then creates all of this together, in one matching style:

  • a poster picture
  • invitation text
  • an anchoring script with an opening, a welcome and a closing
  • a welcome shayari
  • a WhatsApp message
  • three social media captions
  • a programme with times

Each part has a Copy button, and Copy all copies everything. Print / Save as PDF opens a clean page ready to print, and Download page saves it as a file. The poster can be saved as a picture.

Good to know.

  • It needs a Gemini key and can take up to a minute.
  • It only uses the details you type. Anything missing appears as [____], so nothing is made up. Fill those in before you share.
  • The poster is drawn by O.R.V.E.X's own poster studio using exactly the text you typed, so it works without a picture model; still check names, dates and spelling before printing.
  • If the poster fails but the text works, you still get the text.

Add a free Pexels API key as a backup — used only when Google Image Search above isn't set up. Good for generic photos, not specific people or diagrams. Get one free at pexels.com/api (no card needed).

Weather API key (OpenWeather, optional)

Paste an OpenWeather API key to get weather from OpenWeather. Without a key (or if the key is not accepted) O.R.V.E.X uses the free Open-Meteo service. A new key can take up to a couple of hours to start working. Get one free at openweathermap.org/api. The key is stored in this browser and shown as dots.

Web search (Tavily, recommended)

Paste a Tavily API key to give O.R.V.E.X real web search with numbered sources. It is used when a question needs live information (Web Search: Auto or ON). Get one at tavily.com. The key is stored in this browser and shown as dots.
